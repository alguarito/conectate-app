1. Cascada y Especificidad

¿Por qué algunos estilos "ganan" sobre otros? Entender esto es la clave para no frustrarse con el código:

Orden de Cascada

Las reglas se leen de arriba a abajo. Si hay conflicto, la última regla escrita suele ser la que se aplica al elemento.

Especificidad

Un selector de ID (#) es más fuerte que una clase (.), y una clase es más fuerte que una etiqueta (p). ¡La precisión importa!

2. Diseño de Identidad Digital

No solo uses colores, diseña una atmósfera coherente para tu usuario:

Sistemas de Color

Aprende a usar hexadecimal (#fff), RGB y HSL para un control total del espectro visible.

Psicología de Fuente

Las Sans-serif transmiten modernidad, las Serif seriedad. Elige según tu propósito narrativo.

Fondos y Bordes

Gradientes, sombras (box-shadow) y bordes redondeados crean el efecto "Glassmorphism" que ves aquí.

3. Laboratorio de Selectores

Haz clic para identificar qué elemento se vería afectado por cada regla:

Regla: p.activo { }

Afecta solamente a los párrafos que tengan asignada la clase específica "activo".

Regla: section > h2 { }

Afecta solo a los títulos de nivel 2 que sean hijos directos de una sección.
